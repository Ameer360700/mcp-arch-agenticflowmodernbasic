The High-Level Architecture
An agentic flow with MCP relies on three distinct roles:
The MCP Server (The Muscle): This is a standalone Node.js process that holds your tools. 
    It doesn't know why a tool is being called; it just executes it when requested.
The LLM (The Brain): This is the AI model. It looks at the user's request, 
    looks at the available tools, and decides which tool to call next.
The Agent/Orchestrator (The Nervous System): 
    This is your main code loop. It passes messages back and forth between the LLM and the MCP Server. 
    If the LLM says, "I want to use the add tool," the Orchestrator executes it on the MCP server 
    and feeds the result back to the LLM.

Because the LLM needs to handle dynamic steps, the flow operates as a recursive ReAct (Reason + Act) loop:
[User Prompt] 
-> (LLM Plans) 
-> [Tool Call Request] 
-> (Agent Executes Tool) 
-> [Tool Result] 
-> (LLM Evaluates) 
-> (Next Tool Call OR Final Answer)
